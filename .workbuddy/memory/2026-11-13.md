## 发布页 / 编辑器三项修正

   `fontSize 20 → 18`、`fontWeight "700" → "600"`，显式 `paddingHorizontal: 0`
   （Android TextInput 自带左右内边距，不清零标题会比下方正文右缩几像素）。
   注意：这里指的是**发布页的标题输入框**，不是正文里的 H1 样式
   （`ArticleRichTextInput` 的 h1–h6 排版基准 22/20/18/16/15/14 未动）。

2. **彻底删除回车滚动**（原生层，之前两轮只清了 `app/publish` 的 JS 滚动驱动）
   - `react-native-rich-text-fabric`（评论编辑器）：删掉补丁里自己加的
     `scrollCursorToVisible()` —— Android `afterTextChanged` / focus / setSelection /
     insertImage 四处调用 + 方法体，iOS `textViewDidChange` 等五处调用 +
     `scrollRangeToVisible` 方法体。iOS 那处带动画，是抖动主因。
   - `react-native-enriched-html`（文章富文本）：库自带的
     `forceScrollToSelection()` 三处调用 + 方法体一并删除；
     `override fun scrollTo(x,y)` 保留（锁横向滚动，防止 ALIGN_CENTER 位移）。
   - `app/publish` + `components/publish` 无 `scrollTo` 残留；纯文本正文的
     `onContentSizeChange` 只撑高容器、不滚动，保留。

3. **插入视频链接时键盘不弹出**（`components/publish/InputSheet.tsx`）
   根因：sheet 里 `BottomSheetTextInput` 从未被聚焦，也没有 keyboard 相关配置。
   现在 `present()` 后按 60/180/320ms 重试聚焦第一个输入框，`onChange(index>=0)`
   再兜一次；补上 `keyboardBehavior="interactive"` / `keyboardBlurBehavior="none"`
   / `android_keyboardInputMode="adjustResize"`（与 `InlinePostSheet` 一致）。
   三个 sheet（链接 / 视频 / 内联帖子）共用同一组件，一并受益。
   工具栏打开 sheet 前**不要**主动 blur 编辑器：会让键盘收起并可能让工具栏
   在 `toolbarOverlayOpen` 生效前被卸载，sheet 反而弹不出来。

## 经验：patch-package 在 Windows 上重新生成补丁

`npx patch-package <pkg>` 会因 `node_modules/<pkg>/android/build/.transforms/...`
路径过长（git warning: Filename too long）直接以 status 128 失败，`--exclude`
无效。可行做法：先把两个包的 `android/build` 临时 `mv` 到项目外，
生成补丁后再移回：
`mv node_modules/<pkg>/android/build ../_tmp && npx patch-package <pkg> ... ; mv ../_tmp ...`
生成后用 `git apply --check --reverse -p1 --ignore-whitespace patches/<pkg>.patch`
校验补丁与当前 node_modules 一致。本次两个补丁均通过。

原生改动需要重新编译 native app 才生效（`expo run:android` / `run:ios`）。
