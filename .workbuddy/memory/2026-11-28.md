## openapi 第三版对接（后端补齐字段/参数后重新生成）

- 新 spec 修了不少东西：`config`（`DtoUserConfigDto` 全量通知/隐私/水印）、
  `DtoUpdateUserConfigRequest` 的开关字段、`DtoRegisterRequest` 的 `invite_code`/`verification_code`、
  `DtoUpdateContactRequest`、`/article` 的 `sort`、`/search` 的 `category_id`/`sort_by`、
  `/search/tags`、`/search/users`、`/article/browse/history` 的 `order`、`/message` 的 `type`、
  私聊消息 `cursor`/`limit`、`/comment/{id}` 回复分页。
- 因此把上一版所有「拉全量 + 本地过滤 / 只拉第一页」的降级都换回服务端参数；
  `types/compat.ts` 从 7 个类型缩到 5 个，`api/compat.ts` 从 4 个函数缩到 3 个。
- **spec 现在有 25 个 operationId 重复**（同一接口同时留了 camelCase 和 snake_case 两条 path），
  `openapi-generator` 直接报错退出。`package.json` 的 `openapi` 脚本先加
  `--skip-validate-spec` 绕过；后端删掉多余 path 后要去掉这个 flag（交接文档里列了完整 25 条）。
- 仍缺（已写进 `docs/api-compat-handover.md`）：评论 `article`/`parent`、资料
  `equipped_decorations`/`is_followed`、`DtoUserDto.is_followed`、活动内嵌 `article`/`decoration`、
  装饰列表的归属/装备状态、浏览历史 `id`、评论 `sort_by`、`read-all` 的 `type`、socket 事件定义。
- 顺手修了装饰页的老问题：`DecorationCardItem.id` 改 string，DTO → 卡片模型改成真映射
  （之前是 `as unknown as` 硬转，`image_url` 对不上 `imageUrl`，图片全空）。
- 踩坑：`page`/`limit` 在不同接口有的是 number 有的是 string，传参前统一 `String()`，
  别按签名猜。

### 长按保存图片（图片查看器）

- `react-native-gesture-image-viewer` 的手势组合只有双击 / 单击 / 捏合 / 拖动，
  **没有 onLongPress**。方案是在 `renderItem` 里给每张图套一层 `GestureDetector`
  + `Gesture.LongPress().minDuration(450).maxDistance(12).runOnJS(true)`，
  藏在外层 `Race(pinch, Exclusive(pan, tap))` 里面不冲突：手指不动时 pan 不激活，
  450ms 后长按先激活，单击/双击自然失败。
- 保存链路 `lib/saveImage.ts`：`MediaLibrary.requestPermissionsAsync(true)`
  （writeOnly，只要「添加到相册」）→ `File.downloadFileAsync` 下到 `Paths.cache`
  → `Asset.create` → finally 删掉缓存文件。返回 `saved | denied | failed`，
  文案留给调用方。
- 面板 `components/media/ImageActionSheet.tsx`，挂在 ViewerModal 的
  `BottomSheetModalProvider` 里（和 ShareModal 同级）。**成功不弹 toast**：
  面板不立刻关，行内文案切「已保存到相册」+ 主色勾，900ms 后再 dismiss；
  失败/拒绝才走 `showHint`（Modal 内的提示气泡）。
- **React Compiler lint 坑**：`useMemo` 里捕获的回调不能碰任何 ref
  （`react-hooks/refs` 会报 "Passing a ref to a function may read its value during render"），
  所以长按回调只 setState，`saveSheetRef.current?.present()` 挪进
  `useEffect(..., [saveSheetOpen])`。另外在 effect 里读过的 ref 不能在别处写
  （`react-hooks/immutability`），刷新计时器因此不在清理 effect 里读。
- **权限回来了一条**：`expo-media-library` 的插件和 AAR 会带
  `WRITE_EXTERNAL_STORAGE(maxSdkVersion=32)` + `READ_MEDIA_VISUAL_USER_SELECTED`，
  合规阶段删掉的那条只能按功能需要加回来（限 ≤32，13+ 走 MediaStore 不需要）。
  iOS 补 `NSPhotoLibraryAddUsageDescription`；插件里 `granularPermissions`
  限定 `["photo","video"]`，否则会多带 `READ_MEDIA_AUDIO`。
  隐私政策第二节、`docs/store-compliance.md` 权限表同步补「保存图片到相册」。
- 协议正文改了 → `LEGAL_VERSION` 从 "1" 升到 "2"。
- 需要重新编原生包：`expo-media-library` 是原生模块，dev client 里还没有。
