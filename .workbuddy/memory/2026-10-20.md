## ArticleDetail 图片类型「相册下方多一段空白」

**现象**：图片（图集）文章的相册区底下多出一截空白，导致「相册 → 文章标题」的间距
比 mixed（封面 16:9）/ video（播放器 16:9）两个类型大。

**根因**：`ArticleSwiper` 的容器高度写死了兜底值，和实际渲染的图不是同一个比例，
而图是 `objectFit: contain` —— 比例对不上就在上下各留一半空白：

```ts
const firstImageHeight =
  typeof images[0] === "string"
    ? 380                                            // 老数据：写死 380
    : (images[0].height / images[0].width) * width;  // 对象数据：原图尺寸
```
对象数据里 `width/height` 是**原图**的，真正渲染的是 `getImageUrl(item,"large")`
的缩略图，比例可能被裁过；外加 `minHeight: 180` 会把宽幅图撑高。

**修法**（`components/article/ArticleSwiper.tsx`）：
- 新增 `useImageRatio(url, fallback)`：用 `Image.getSize` 量**实际展示的那张图**的比例，
  模块级 `imageRatioCache` 按 URL 缓存，只量一次；对象数据先用 `width/height` 兜底首帧。
- 高度改成 `clamp(ratio * 屏宽, 100, 480)`，容器上不再挂 `minHeight`/`maxHeight`，
  比例和容器一致 → contain 不留竖直空白。
- 下限从 180 降到 100：下限只要高于图片比例就会重新产生留白，横幅图宁可矮一点。

**注意**：相册高度仍按「首图」定，滑动到其它比例的图时容器不跳变（相册惯例）；
如果要求每页自适应，就把 ratio 换成 `images[currentPage]` 的。
`eslint` 的 `react-hooks/set-state-in-effect` 不允许在 effect 里同步 setState，
所以 ratio 用「渲染时读缓存 + 异步量到后 setState」的派生写法，不要写回 state。

## 翻译标语在「纯数字」内容上也显示

**现象**：文章标题 / 正文只有数字（`12345`、`12:30`、`$19.99`）时，
ArticleDetail 顶上照样挂「已翻译」标语 + 原文/译文切换按钮。

**根因**：判定只看「有没有调用过翻译」，不看「有没有真的翻出不一样的东西」：
- `translateText` 对任何非空文本都发请求，返回的译文和原文一样，
  `useTranslate` 仍把 `showTranslated` 置 true → `titleTranslation !== null`
- `translateHtml` 里 `needsTranslation` 已经按文本节点过滤纯数字，但它仍然
  `return { html }`（原样），调用方照样 `setTranslateStatus("done")`
- 标语条件 `titleTranslation !== null || translateStatus === "done"` 只要命中就显示

**修法**：
1. `lib/translate.ts` 新增导出 `hasTranslatableContent(text)`：先剔除
   `pre/code/script/style` 等不送翻节点再剥标签，最后复用 `needsTranslation`
   的 `\p{L}` + 非纯数字符号判定。`translateText` 与 `translateHtml` 都在入口短路。
2. `hooks/useTranslate.translate()`：源码没有可翻内容时 `setShowTranslated(false)` 后直接返回，
   不再把原文当译文塞进 state。
3. `app/article/[id].tsx`：
   - 正文翻译 effect 的早退条件加上 `!hasTranslatableContent(html)`
   - 标语条件从「有译文 / 状态 done」改成「**译文和原文确实不同**」
     （`titleWasTranslated` / `contentWasTranslated` 各比一次 trim 后字符串），
     这样旧缓存里存过的「纯数字译文」也不会再触发标语。

验证：用 esbuild 把 `lib/translate.ts` 打到 node 里跑 12 组用例
（`12345` / `· · ·` / `<p><img></p>` / `😀😀` / `<pre>const a=1</pre>` → false；
`你好` / `hello 123` / `2026 年 10 月` → true）全部符合预期。

**注意**：`app/article/[id].tsx`、`hooks/useTranslate.ts` 本来就有 9 个
`react-hooks/refs` / `set-state-in-effect` 报错（HEAD 版本同样 9 个），本次未新增。
