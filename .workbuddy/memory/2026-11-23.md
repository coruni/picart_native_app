# 2026-11-23

## 登录页（app/auth/index.tsx）

- 协议勾选改为只约束快捷登录：`openEmailLogin` 不再校验 `agreed1/agreed2`，直接进
  `login` 面板；新增 `ensureConsent()`，仅 QQ / 微信按钮（`handleProviderPress`）在
  未勾选时 toast `auth.consentRequired`。注册面板仍强制勾选（`canSubmit` 里判断）。
- `AgreementFields` 里两个可跳转链接（社区用户协议 / 社区隐私政策）在前后各插一个
  `{" "}`。嵌套 `Text` 不支持 margin/padding（inline 布局），间距只能用空格字符实现，
  否则中英文都会和相邻文案贴在一起。全项目只有这两处 `<Text onPress>` 内联链接。
- **两处协议勾选互相独立**：落地页（`providers`，快捷登录用）状态在 `AuthScreen` 里；
  账号密码登录面板（`LoginPanel`）有自己的 `useState`，且 `canSubmit` 要求两条都勾。
  `openEmailLogin` 只负责切面板、不拦勾选 —— 落地页的协议只拦 QQ / 微信。
- 字号回退到改版前（参考提交 `6108167` 的旧版登录页）：落地页标题 25/800 → 22/700
  （= 旧版「面板标题 22/700」，也是 `DESIGN_CONSTRAINTS.md` 3.6 的规定），
  provider 按钮文案 16 → 15（旧版无此按钮，取旧版最常用的 15 档）。
  注意设计约束明确禁止 25 这种中间字号。
- **面板切换动画回滚到旧版 react-native `Animated`**（`Animated.Value` × 2 +
  `Animated.parallel` + `useNativeDriver: true`），不再用 reanimated。淡出 180ms /
  translateY 12 → 换屏 → 从 opacity 0 / translateY 20 淡入 220ms。
  动画只包住面板本体（logo 与 header 静止），与旧版结构一致。
  ⚠️ 本项目登录页动画**必须走 native driver**，不要改回 JS 逐帧（reanimated 或
  Animated 不带 native driver 都不行）。
- **页面 gutter 统一 16**（`DESIGN_CONSTRAINTS.md` 2.3）：删除 24 / 29 / 16 三套
  `paddingHorizontal`，只留 `scrollContent: 16`；header 改 8 + 40×40 按钮，使图标左边缘
  正好落在 16 上；`footerRow` 去掉 `paddingHorizontal: 4` 让「忘记密码」与输入框左边缘
  对齐。顺手把 provider 按钮的 53/13/12/15 归到标准 52/12/16/16。
- **品牌区位置固定**：删掉 `logoAreaLanding` / `logoAreaForm` 两套外边距（36/28 vs
  24/36），落地页与各面板共用 `logoArea`（24 上 / 28 下 / minHeight 48），否则切换
  登录方式时 APP 名称会上下跳 12px。
- **关闭图标改用 hugeicons `Cancel01Icon`**：删除自定义 `CloseGlyph`（自绘 SVG 叉）
  与 `react-native-svg` 依赖，和全站其他关闭按钮（`Cancel01Icon` + `HugeIcon`）统一。
